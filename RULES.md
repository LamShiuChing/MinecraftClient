# Series Rules

**Core rule: the client can break physics, not the economy.**
It changes how you move, fight, see and interact. It never creates anything. Every item, block and XP point is mined, crafted, looted, traded or dropped in normal survival.

1. **World:** Hardcore, cheats **off** at creation, random seed, never opened to LAN with cheats.
2. **Nothing outside survival:** no `/commands`, no creative or spectator mode, no F3+F4 game mode switching, no data packs, no editing world files.
3. **No other mods** except Overkill, plus performance or recording mods (e.g. Sodium) that change no gameplay.
4. **Nothing from nothing:** no item spawning, no duplication glitches, no setting health, hunger, XP or effects directly. Auto-eat and auto-totem are fine because they use items you really have.
5. **Changing the world is fine if it follows the rules:** mining 500 blocks at once is allowed because the blocks drop normally. Placing blocks uses blocks from your inventory.
6. **Everything is visible:** the HUD module list is always on screen, so viewers see every active cheat.
7. **Speed episodes are uncut,** with the Stopwatch on screen.
8. **Every episode adds something:** a new module, or a stunt that wasn't possible before.
9. **If you die, the season ends.**
